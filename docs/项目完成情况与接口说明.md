# 项目完成情况与接口说明

> 项目：考研AI导学平台（kaoyan-rbac）—— rjgc 旧版的鉴权框架重写版
> 技术栈：FastAPI + SQLAlchemy 2.x + AuthX(JWT) + argon2 + Vue 3 + Vite + Element Plus
> 更新日期：2026-11-08

## 一、功能完成情况

| # | 需求 | 状态 | 说明 |
|---|------|------|------|
| 1 | 框架鉴权 + 基于角色的权限控制（RBAC） | ✅ 完成 | AuthX 签发/校验 JWT（HS256），含吊销名单与密码版本号；7 表 RBAC 模型 |
| 2 | 只渲染已授权菜单/按钮，未授权不显示不传数据 | ✅ 完成 | 菜单按权限过滤、路由 `meta.perm` 守卫、按钮级 `v-permission` 指令；所有管理接口服务端强制鉴权 |
| 3 | 密码加盐慢哈希 + 会话凭证 + 失败统一提示 | ✅ 完成 | argon2 慢哈希；登录失败统一"账号或密码错误"；5 次失败锁定 600 秒；哑哈希防计时侧信道 |
| 4 | 邮箱验证码登录 | ✅ 完成 | 6 位验证码 / 300 秒有效 / 一次性 / 错 5 次作废 / 60 秒重发冷却；QQ 邮箱 SMTP 真实发信，开发期失败可降级控制台回显 |
| 5 | 注册数据规范提示 | ✅ 完成 | 用户名 3-50 位、密码 8-64 位字母+数字、邮箱格式校验，422 返回"字段: 原因" |
| 6 | 忘记密码模块 | ✅ 完成 | 邮箱验证码重置密码；重置后清登录锁定、作废旧令牌（密码版本号 +1） |

附加已完成：审计日志（登录/注册/重置/授权变更）、退出登录令牌吊销、`/api/db-check` 数据库自检（生产环境 404）、`/static/file_test.html` 仅开发环境可访问、**图形验证码人机验证**（密码登录连续失败 2 次后强制，SVG 验证码一次性、300 秒过期、复用失败计数三维度键）。

未实现（不在本次交付范围）：短信通道、业务模块真实功能（AI 问答 / 文件 / 学习计划仅有 `/ping` 占位）、发码接口 IP 限流。

## 二、内置数据

- 角色：`考研学生`(role_id=1，7 项权限)、`系统管理员`(role_id=2，全部 16 项权限)
- 权限：`模块:操作` 格式，覆盖 择校/刷题/模考/复试/学习计划/资讯/后台管理 7 个模块共 16 条
- 初始管理员：`admin` / `Admin@123456`（首次启动幂等创建）

## 三、接口清单

统一约定：除注册/登录/发码/重置密码/图形验证码外，均需请求头 `Authorization: Bearer <access_token>`；错误响应格式 `{"code":..., "message":..., "data":...}`。细分业务码：`40010` = 图形验证码缺失/错误（前端据此展示验证码框）。

### 系统

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/` | 服务自检 |
| GET | `/api/db-check` | 数据库连接测试（仅非生产环境，生产返回 404） |
| GET | `/static/file_test.html` | 文件上传测试页（仅开发环境） |
| GET | `/docs` | Swagger 交互文档 |

### 用户模块 `/api/user`

| 方法 | 路径 | 鉴权 | 请求体 / 说明 |
|------|------|------|--------------|
| POST | `/register` | 否 | `{username, email, password, nickname?}` → 201 + 用户简要信息 |
| POST | `/login` | 否 | `{username, password, captcha_id?, captcha_code?}`（username 可填用户名或邮箱）→ `{access_token, expires_in, user, roles, permissions}` |
| GET | `/captcha` | 否 | 图形验证码 `{captcha_id, svg, expires_in}`；密码登录连续失败 2 次后登录请求必须携带，否则返回 `code=40010` |
| POST | `/login/email` | 否 | `{email, code}` 邮箱验证码登录 → 同上 |
| POST | `/email-code` | 否 | `{email, purpose}` purpose ∈ `login`/`reset`/`register`；响应 `channel=smtp` 为真实发信 |
| POST | `/password/reset` | 否 | `{email, code, new_password}` 忘记密码重置 |
| POST | `/password/change` | 是 | `{old_password, new_password}`，修改后需重新登录 |
| POST | `/logout` | 是 | 吊销当前令牌 |
| GET | `/me` | 是 | 当前用户信息（含角色与权限） |
| PUT | `/me` | 是 | 修改个人信息（昵称/专业/目标院校地区/备考阶段/目标分数） |
| GET | `/permissions` | 是 | `{roles, permissions}`，前端渲染菜单用 |
| GET | `/ping` | 否 | 模块自检 |

### 后台管理 `/api/admin`（均需对应权限）

| 方法 | 路径 | 所需权限 | 说明 |
|------|------|----------|------|
| GET | `/roles` | `role:manage` | 角色列表 |
| POST | `/roles` | `role:manage` | 新增角色 |
| PUT | `/roles/{role_id}` | `role:manage` | 修改角色 |
| DELETE | `/roles/{role_id}` | `role:manage` | 删除角色（内置角色不可删） |
| GET | `/permissions` | `perm:view` | 权限清单（按模块分组） |
| GET | `/roles/{role_id}/permissions` | `role:manage` | 某角色已授权限 ID 列表 |
| PUT | `/roles/{role_id}/permissions` | `role:manage` | 覆盖式保存角色授权 |
| GET | `/users?page=&page_size=` | `user:manage` | 用户列表（含角色） |
| PUT | `/users/{user_id}/roles` | `user:manage` | 分配用户角色 |
| PATCH | `/users/{user_id}/status` | `user:manage` | 启用/禁用账号 |
| GET | `/audit-logs?page=&page_size=` | `role:manage` | 审计日志（时间倒序） |

## 四、典型调用流程

```
注册        POST /api/user/register
密码登录    POST /api/user/login            → 保存 access_token
            （连续失败 2 次后：先 GET /api/user/captcha 取图形验证码，
              登录请求带 captcha_id + captcha_code，错误/缺失返回 code=40010）
取权限      GET  /api/user/permissions      → 渲染菜单/按钮
邮箱登录    POST /api/user/email-code       → 收邮件取 6 位码
            POST /api/user/login/email
忘记密码    POST /api/user/email-code (purpose=reset)
            POST /api/user/password/reset   → 用新密码重新登录
退出        POST /api/user/logout           → 令牌立即失效
```
