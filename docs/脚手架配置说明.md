# 脚手架配置说明

## 一、整体结构

```
kaoyan-rbac/
├── backend/                # FastAPI 后端
│   ├── app/
│   │   ├── main.py         # 应用入口（路由注册、异常处理、启动钩子）
│   │   ├── core/           # 底座：配置/数据库/安全/RBAC/存储/邮件/种子/审计/异常
│   │   ├── models/         # SQLAlchemy 模型（sys_user 等 7 张 RBAC 表 + 业务占位表）
│   │   ├── modules/        # 业务模块：user / rbac / ai_chat / file / study_plan
│   │   └── schemas/        # Pydantic 请求/响应模型
│   ├── .env                # 本地环境配置（含敏感凭据，勿提交仓库）
│   └── requirements.txt    # Python 依赖
├── frontend/               # Vue 3 前端
│   ├── src/
│   │   ├── api/            # axios 接口封装（auth.ts / rbac.ts）
│   │   ├── config/menu.ts  # 菜单配置（按权限过滤）
│   │   ├── directives/     # v-permission 按钮级权限指令
│   │   ├── layouts/        # DefaultLayout（侧边菜单 + 顶栏）
│   │   ├── router/         # 路由与 meta.perm 守卫
│   │   ├── stores/auth.ts  # Pinia 登录态（token / hasPerm / isAdmin）
│   │   ├── types/          # TS 类型定义
│   │   ├── utils/request.ts# axios 实例（拦截器统一解包/错误提示）
│   │   └── views/          # 页面（Login/Register/Home/Profile/admin 三个管理页等）
│   ├── vite.config.ts      # @ 别名 + /api 代理
│   └── package.json
└── docs/                   # 项目文档
```

## 二、后端脚手架

| 项 | 配置 |
|----|------|
| Web 框架 | FastAPI（Swagger 文档自动暴露在 `/docs`） |
| ORM | SQLAlchemy 2.x（DeclarativeBase），模型集中在 `app/models/` |
| 数据库 | 开发默认 SQLite 单文件 `app_local.db`（`USE_SQLITE=true`）；生产改 `USE_SQLITE=false` 走 MySQL（pymysql） |
| 认证 | AuthX（JWT，HS256），令牌携带密码版本号 `pv`，改密/重置后旧令牌全部失效 |
| 密码 | argon2-cffi 慢哈希加盐 |
| 键值存储 | Redis 优先，连接失败自动降级为进程内内存（验证码/登录锁定/吊销名单共用） |
| 邮件 | 标准库 smtplib + SSL，QQ 邮箱 SMTP（465 端口 + 授权码） |
| 配置 | `app/core/config.py` 用 `os.getenv` 读取 `.env`（python-dotenv），无 pydantic-settings 依赖 |
| 启动钩子 | `AUTO_CREATE_TABLES=true` 自动建表；`AUTO_SEED=true` 幂等写入角色/权限/管理员 |

### `.env` 关键项

```ini
APP_ENV=development          # production 下会关闭 db-check/static/验证码回显
SECRET_KEY=<随机 hex>        # JWT 签名密钥
USE_SQLITE=true              # false 时走下方 DB_* MySQL 配置
REDIS_ENABLED=false          # true 时优先用 Redis
MAIL_ENABLED=true            # 真实 SMTP 发信
MAIL_HOST=smtp.qq.com
MAIL_PORT=465
MAIL_USERNAME=<发件QQ邮箱>
MAIL_PASSWORD=<QQ邮箱授权码>  # 注意是授权码不是登录密码
MAIL_FALLBACK_CONSOLE=true   # 发信失败时降级控制台回显（仅开发）
CAPTCHA_AFTER_FAILURES=2     # 密码登录失败几次后强制图形验证码
CAPTCHA_TTL_SECONDS=300      # 图形验证码有效期(秒), 一次性
ADMIN_LOGIN_NAME=admin
ADMIN_INITIAL_PASSWORD=Admin@123456
```

## 三、前端脚手架

| 项 | 配置 |
|----|------|
| 框架 | Vue 3.5 `<script setup>` + TypeScript strict |
| 构建 | Vite 6，`@` → `src` 别名；`npm run build` = `vue-tsc -b && vite build`（先类型检查再打包） |
| UI | Element Plus（全局注册）+ @element-plus/icons-vue |
| 状态 | Pinia（`stores/auth.ts` 持久化 token 与用户权限） |
| 路由 | vue-router 4，路由 `meta.perm` 声明所需权限，全局守卫拦截 |
| HTTP | axios，拦截器统一解包 `{code,message,data}` 并处理 401 跳登录 |
| 代理 | `vite.config.ts` 中 `/api` → `http://127.0.0.1:8001`，前端代码里只写 `/api/...` |

### 权限三件套（保持"未授权不显示"）

1. **菜单**：`config/menu.ts` 每项带 `perm`，按登录用户权限过滤
2. **路由**：`router/index.ts` 守卫校验 `meta.perm`，无权限跳 404/首页
3. **按钮**：`v-permission="'role:manage'"` 指令，无权限直接移除 DOM

### tsconfig 要点

- `tsconfig.json` 为 references 结构，分 `tsconfig.app.json`（业务代码，`@/*` 路径映射）与 `tsconfig.node.json`（vite.config.ts，含 `"types": ["node"]`）
- `noUnusedLocals/noUnusedParameters` 关闭，避免占位代码报错
