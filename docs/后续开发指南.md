# 后续开发指南

> 面向在本项目（kaoyan-rbac）上继续开发业务功能的同学。
> 鉴权/RBAC 已完整交付，业务模块（AI 问答、文件、学习计划）目前只有 `/ping` 占位路由与占位模型。

## 一、新增一个业务模块的标准步骤

以开发「学习计划」为例：

### 1. 后端

**模型**：替换 `app/models/plan.py` 的占位表为真实表结构，并在 `app/models/__init__.py` 中确认导出（不导出则 `create_all` 不会建表）。

**接口**：在 `app/modules/study_plan/router.py` 中添加路由，用现成依赖接线鉴权：

```python
from fastapi import APIRouter, Depends
from typing import Annotated
from app.core.deps import CurrentUser, DbSession
from app.core.rbac import require_permission
from app.models.user import User

router = APIRouter(prefix="/api/study-plan", tags=["学习计划模块"])

# 登录即可用：
@router.get("/my")
def my_plans(user: CurrentUser, db: DbSession):
    ...

# 需要指定权限（权限键对应 seed.py 中的 16 条之一）：
PlanWriter = Annotated[User, Depends(require_permission("studyplan:add"))]

@router.post("")
def create_plan(user: PlanWriter, db: DbSession):
    ...
```

- `CurrentUser`：要求登录，自动完成令牌校验/吊销检查/密码版本检查
- `require_permission("模块:操作")`：要求登录 + 指定权限，系统管理员（role_id=2）自动放行
- 越权返回 403，未登录返回 401，无需自己写

**权限不够用时**：在 `app/core/seed.py` 的 `PERMISSION_SEEDS` 增加条目（格式 `模块:操作`，模块名限 7 个取值之一），并在 `STUDENT_PERMISSION_KEYS` 决定是否发给学生。重启自动幂等补种；已有库可在「角色管理」页手工勾选。

**审计**：重要操作调用 `app/core/audit.py` 的记录函数写 `sys_audit_log`。

### 2. 前端

1. `src/api/` 新建接口封装文件，用 `request.get/post(...)`（已统一解包）
2. `src/views/` 新建页面组件
3. `src/router/routes.ts` 加路由，`meta: { perm: 'studyplan:view' }`
4. `src/config/menu.ts` 加菜单项（带同一个 `perm`）
5. 页面内按钮用 `v-permission="'studyplan:add'"` 控制显示

完成后 `npm run build` 必须通过（含 vue-tsc 类型检查）。

## 二、开发纪律

- **服务端鉴权为准**：前端隐藏只是体验优化，任何接口都必须挂 `require_permission`，禁止只藏不拦
- **不改鉴权语义**：登录失败统一提示、5 次锁定 600 秒、验证码 6 位/300 秒/一次性/60 秒冷却等口径来自需求文档，调整前先改文档
- **生产红线**：`APP_ENV=production` 时必须 `MAIL_FALLBACK_CONSOLE=false`、配置真实 Redis（多 worker 下内存存储不共享，会导致锁定/吊销失效）
- **`.env` 含邮箱授权码与 SECRET_KEY，禁止提交仓库**
- 数据库结构变更：开发期可删 `app_local.db` 重建；数据重要时应引入 alembic 迁移
